# Planitt

Planitt is an intelligent planning platform for retail, integrating POS, Planogram optimization, and forecasting.

## Modules

- **[Website](./Website)**: The main marketing and landing page.
- **[POS System](./POS)**: Point of Sale system with Backend and Frontend.
- **[Planogram Platform](./PlanogramPlatform)**: Admin platform for planogram management.
- **[Mobile App](./MobileApp)**: Mobile application for store staff.
- **[Python Models](./PythonModels)**: AI/ML models for compliance, forecasting, and optimization.

## Getting Started

Please refer to the `README.md` in each subdirectory for specific running instructions.
