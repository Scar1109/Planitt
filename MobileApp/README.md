# Planitt Mobile App

React Native / Expo application for store staff.

## Prerequisites

- Node.js (v18+)
- Expo CLI (optional, usable via npx)

## How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Application**:
    ```bash
    npm start
    ```
    Scan the QR code with Expo Go (Android/iOS) to run on your device.
