# POS Backend

The backend service for the Point of Sale system.

## Prerequisites

- Node.js (v18+)
- MongoDB (optional, if local DB is needed)

## How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Server**:
    ```bash
    npm start
    ```
    The server runs on **Port 4000** by default.
