# POS Frontend

The frontend interface for the Point of Sale system.

## Prerequisites

- Node.js (v18+)

## How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:5174](http://localhost:5174) in your browser.
