# Planogram Platform Frontend

The frontend interface for managing planograms.

## Prerequisites

- Node.js (v18+)

## How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:5175](http://localhost:5175) in your browser.
