# Planitt Website

The landing page and marketing website for Planitt.

## Prerequisites

- Node.js (v18+)

## How to Run

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Start Development Server**:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:5173](http://localhost:5173) in your browser.
